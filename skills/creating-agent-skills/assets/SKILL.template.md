# Judul Skill

Satu-dua kalimat: apa hasil akhirnya dan mengapa skill ini ada.

## Persiapan

- Tool/dependensi yang dibutuhkan (`jq`, `gh`, Python 3.10+).
- Environment variable yang harus sudah diset: `NAMA_API_KEY` (jangan pernah ditulis di file ini).

## Alur kerja

```
- [ ] 1. ...
- [ ] 2. ...
- [ ] 3. Verifikasi hasil
```

**1. Langkah pertama.** Apa yang dilakukan dan mengapa.

**2. Langkah kedua.** Perintah persis bila langkahnya rapuh:

```bash
python3 scripts/contoh.py --input data.json
```

**3. Verifikasi.** Cara memastikan hasilnya benar. Bila gagal, kembali ke langkah N.

## Format output

Template atau contoh input → output.

- Hal yang sering salah dan cara menghindarinya.
